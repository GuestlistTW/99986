# 彩虹乾杯輪盤 Pride Spin

2026 台灣同志遊行活動抽獎頁。轉盤先轉出任務（喝一杯、跳舞、全場乾杯…），再從名單隨機跳出一位得主，顯示名字與 IG。

## 放到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `pride-spin`），把 `index.html`、`README.md`、`.gitignore` 上傳上去。
   最簡單的方式：在 repo 頁面點 **Add file → Upload files**，把檔案拖進去，再按 **Commit changes**。
2. 到 **Settings → Pages**，把 Source 設成 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
3. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/pride-spin/`。

## 內建名單

報名名單（372 人）已經直接寫在 `index.html` 裡（搜尋 `const LIST=`）。任何裝置第一次打開網址，就會自動載入這份名單，並記在那台裝置上。

注意：repo 是公開的，名單內容任何人都看得到。

要更新名單，可以直接在 GitHub 上編輯 `index.html` 裡的 `LIST`，每行格式是 `["報名編號","姓名","IG"],`；或把新的 Excel 交給 Claude 重新產生。改完後，已經打開過的裝置要到「名單 / 設定」按「重新載入內建報名名單」才會換成新名單。

## 名單怎麼維護

所有名單操作都在網頁右上角的「名單 / 設定」裡完成，不需要改程式碼。

| 情況 | 做法 |
| --- | --- |
| 第一次使用 | 打開網址就會自動載入內建名單，不用另外匯入 |
| 臨時有人加入 | 按右上角「＋ 臨時加人」，輸入名字和 IG，按「加入」（Enter 也可以） |
| 有人沒來 / 填錯 | 在名單裡搜尋這個人，按「刪除」兩次 |
| 報名表又多了一批人 | 只把新的那幾行另存成 Excel 或直接複製貼上，選「加到目前名單後面」 |
| 換另一台裝置 | 打開網址就會載入內建名單。若舊裝置上有臨時加的人，先在舊裝置按「下載名單 CSV」，再到新裝置上傳 |
| 想回到原始名單 | 「名單 / 設定」→「重新載入內建報名名單」，按兩次確認（會清除抽中紀錄和臨時加的人） |
| 活動結束要留紀錄 | 按「下載得主 CSV」，裡面有順序、報名編號、名字、IG、抽到的任務和時間 |

匯入規則：

- 會自動找「姓名」「IG帳號」「報名編號」「報名狀態」這幾欄，欄位順序不影響。
- 「報名狀態」寫「取消」的不會匯入。
- IG 寫「無」或空白，抽中時只顯示名字。
- 表單裡出現幾行，就有幾次機會。同一個 IG 登記多位朋友時，每位各算一次。

## 活動當天

1. 在現場要用的手機（或電腦）打開網址，確認名單是 372 人。建議前一天先開一次。
2. 先試轉幾次，確認音效和畫面，再按「清除紀錄」（按兩次）歸零。
3. 按「全螢幕」，之後按空白鍵或「轉！」就能抽。
4. 現場有人加入，按「＋ 臨時加人」即可，不用重新整理頁面。

抽中的人預設不會再被抽到，可以在設定裡關掉。

## 修改轉盤選項

在「名單 / 設定」最下面，每行一格：

```
中文 | English | 1
```

最後的 `1` 代表轉到之後要抽一個人，`0` 代表不抽人（例如「全場乾杯」「再轉一次」）。同一個選項寫兩行，出現機率就加倍。
